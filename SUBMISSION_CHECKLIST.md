# Submission checklist

- [ ] Upload `index.html` (rename the folder to eternal-dawn) to a **public GitHub repo** along with README.md, LICENSE and tools/
- [ ] Turn on **GitHub Pages** (Settings → Pages → Deploy from branch) **or** drag the folder onto app.netlify.com/drop
- [ ] Test the app link in a **private/incognito window** (no login needed) and on a phone
- [ ] Record the **≤30 s demo video** (see DEMO_VIDEO_SCRIPT.md) with English subtitles → upload to YouTube (public or unlisted)
- [ ] Project page: upload `banner.png` + screenshots (all under 10 MB)
- [ ] Paste the text from PROJECT_PAGE_TEXT.md and fill in the links and team names
- [ ] All teammates are registered and listed on the Members tab
- [ ] Optional: FortiGuard Web Filter Classification (category: Education; Company: N/A)
- [ ] Submit before 11:59 pm local time of your Local Event

## Copyright check before sharing
- [ ] Video uses only our screen recordings + royalty-free (or no) music
- [ ] Project page images are only banner.png and files from screenshots/ (no downloaded or reference photos)
- [ ] No NASA or agency logos anywhere
- [ ] THIRD_PARTY_NOTICES.md and LICENSE are in the GitHub repo
- [ ] Credits section is visible at the bottom of the app
